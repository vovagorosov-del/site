Тест ИИ-помощника

Вставь свой Gemini API-ключ в поле ниже и проверь чат. Ключ нужен только на этой странице, в код сайта он не записывается.

Только для личного теста. Прямой вызов Gemini из браузера не подходит для публичного использования: ключ можно увидеть в инструментах разработчика и сетевом запросе. Не присылай ключ в чат и не сохраняй страницу с ключом. Для общего сайта используй Cloudflare Worker.

Ключ не сохраняется в localStorage или файлах. Он используется только для запросов из этой вкладки к Google Gemini.

Привет! Расскажи, какую тему или идею проекта ты рассматриваешь. Я помогу продумать её и составить план.

Не отправляй личные, школьные учётные или другие чувствительные данные. Запрос отправляется Google Gemini и может расходовать квоту API.

Для включения помощника на основном сайте настрой Cloudflare Worker по инструкции в worker/README.md.
